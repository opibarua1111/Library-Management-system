# 📚 Library Management System (Web API)

A **.NET Core 8.0 Web API** project for managing a library.  
Supports **CRUD operations** for Books, Authors, Categories, Members, Loans, Fines, and Reservations.  
Uses **Entity Framework Core** with **SQL Server** and **Guid IDs** for all entities.

---

## 🚀 Features
- 📖 Manage Books, Authors, and Categories  
- 👥 Manage Members and their Loans/Reservations  
- 💰 Track Fines for overdue returns  
- 🔗 Many-to-Many relationship between Books & Authors  
- 🗃️ Database migrations with EF Core  
- 🌐 RESTful API endpoints with Swagger UI  

---

## 🛠️ Technologies
- **.NET 8 Web API**
- **Entity Framework Core 8**
- **SQL Server**
- **Swagger / OpenAPI**
- **C# 12**
